Requirements:
- Write a function `build_model(rpm: float) -> torch.nn.Module`.
- Use only torch and numpy. Use standard layers (Conv1d, Linear, ReLU, pooling, normalization). You may compute weights with numpy formulas and copy them into the layers.
- The model must work as written: no training loop, no fitting to data.

Reply with a single Python code block and nothing else.
